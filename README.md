# RPG Platform

Plataforma de RPG para organizar personagens, campanhas e materiais de jogo, com experiências próprias para jogadores e mestres.

**Fase atual:** descoberta e definição do MVP. Este repositório contém a base documental; ainda não há aplicação executável, hospedagem ou funcionalidades implementadas.

## Visão do produto

Construir um produto que possa atender múltiplos grupos e evoluir para uma oferta comercial. O nome é provisório. Público inicial, sistemas de RPG suportados, diferenciais e modelo de negócio ainda serão definidos.

## Escopo inicial confirmado

- Painel do jogador com seus personagens e campanhas.
- Painel do mestre com campanhas, notas, NPCs e fichas.
- Área para adicionar e organizar mapas das campanhas.
- Desenvolvimento em repositório próprio, com possibilidade de publicação do código no futuro.
- Avaliação de hospedagem no homelab, sem dependência obrigatória de sua infraestrutura.

Estas funções estão planejadas; não estão implementadas.

## Desenvolvimento

A escolha de linguagem, framework, banco, mecanismo de mapas e infraestrutura está pendente da descoberta do produto. Não há dependências para instalar ou comando para iniciar uma aplicação nesta etapa.

Dados de teste devem ser fictícios. Mapas, imagens, fichas e conteúdo de sistemas de RPG precisam ter origem e permissão de uso conhecidas; os uploads de usuários não devem ser versionados.
